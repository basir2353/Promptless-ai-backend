3. The Problem We Solve
   Every professional repeats this loop hundreds of times a week:
   Stop working and open a chatbot in another tab.
   Copy content out of the app they're using.
   Write a prompt describing what they want.
   Wait for the answer, then copy it back.
   Return to the task and apply it by hand.
   Each of these is a context switch — and context switches destroy focus. The problem is not that AI isn't smart enough; it's that reaching it costs too much attention. We remove the loop entirely: the help comes to the user, in place.
4. What We're Building
   Promptless AI is a proactive AI assistant that sits alongside every app and helps the user BEFORE they ask. With permission, it understands the live context — the active app, page, selection, code file, design, or spreadsheet — and offers relevant, one-click actions right where the work is happening.
   Normal AI today
   Promptless AI (what we build)
   User opens it and writes a prompt
   It comes to the user with a suggestion
   Lives in a separate browser tab
   Lives inside every app
   Returns text you copy-paste
   Performs the action in one click
   Forgets everything each session
   Remembers across apps and over time

7. How It Works — All Use Cases
   Every use case follows the same pattern: the AI reads context, notices an opportunity, and offers a one-click action with the impact and time saved. This is the heart of the product — understand these well.
   7.1 Coding (VS Code / Cursor)
   It detects: the language, project structure, errors, duplicated components, missing auth, absent env vars.
   It offers: merge duplicates, add authentication, fix the missing deploy variable — each in one click.
   7.2 Design (Figma)
   It detects: inconsistent spacing, low-contrast buttons, missing mobile layouts.
   It offers: apply an 8px grid, fix contrast to accessible colors, auto-generate a responsive version.
   7.3 Shopify
   It detects: a product page with low-conversion signals and weak CTAs.
   It offers: a CRO audit: trust badges, sticky Add-to-Cart, reviews placement, upsell — with instant preview.
   7.4 Email
   It detects: an email that's too long, too aggressive, grammatically weak, or missing a CTA.
   It offers: one-click improve — tighten length, soften tone, fix grammar, add a call to action.
   7.5 Excel
   It detects: duplicate rows, missing formulas, wrong totals, outliers.
   It offers: clean and correct the data, then generate the right chart automatically.
   7.6 Browser / Reading
   It detects: the user reading a long article or research page.
   It offers: summarize, fact-check, and save key insights to their knowledge base.
   7.7 YouTube / Learning
   It detects: a tutorial or lecture is playing.
   It offers: generate notes, pull code snippets, and create quizzes and flashcards.
   7.8 Meetings (Zoom / Meet)
   It detects: a live call in progress.
   It offers: take notes with speaker attribution, capture decisions, create Jira tickets, draft follow-up emails.
